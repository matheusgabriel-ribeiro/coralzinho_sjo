# 🎶 Coralzinho SJO

> Louvando a Deus através da música e unindo corações pela fé.

O **Coralzinho SJO** é uma landing page desenvolvida para apresentar o coral, compartilhar sua história, missão e propósito, além de reunir momentos especiais em uma galeria de fotos.

🔗 **[Acessar o site](https://matheusgabriel-ribeiro.github.io/coralzinho_sjo/)**

---

## 📸 Sobre o projeto

O projeto foi desenvolvido com o objetivo de criar uma página web institucional para o Coralzinho SJO, proporcionando aos visitantes uma apresentação sobre o grupo e seus objetivos.

A página reúne informações sobre a história do coral, sua missão de evangelizar através da música e uma galeria de momentos especiais.

## ✨ Funcionalidades

- **Apresentação institucional:** introdução ao Coralzinho SJO.
- **Sobre nós:** informações sobre a história, objetivo e missão do coral.
- **Layout responsivo:** adaptação da página para diferentes dispositivos.
- **Galeria de fotos:** apresentação de momentos especiais.
- **Navegação interna:** acesso direto à seção "Sobre Nós".
- **Página de inscrição:** link para a página de inscrição.
- **Links externos:** acesso ao Instagram e localização do coral.

## 🛠️ Tecnologias utilizadas

- HTML5

## 🚀 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/matheusgabriel-ribeiro/coralzinho_sjo.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd coralzinho_sjo
   ```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no Visual Studio Code.
